# Code of conduct

This project welcomes contributors of every background and experience level.

## Expected behavior

- Be respectful, constructive, and patient in issues, reviews, and discussions.
- Critique ideas and code, not people.
- Respect privacy: never post another person's data, metrics, or identity from a real enterprise.
- Assume good intent and ask clarifying questions.

## Unacceptable behavior

Harassment, discrimination, personal attacks, sexualized language or imagery, doxxing, and sustained disruption are not tolerated.

## Enforcement

Maintainers may edit or remove contributions and restrict participation for behavior that violates this code. Report concerns privately to the repository maintainers through GitHub rather than in a public thread.
